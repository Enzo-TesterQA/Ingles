Lo que dijiste
Okay, the first thing is to reproduce, to try to reproduce the failure by running the test several times, locally and in in CI. To confirm it's really flaky test and not a real bug. Then I look for the root cause. Usually it's time in issues share a state between test or on a scalable test data. For example, I once replaced fixed weights with explicit weights and the failures disappear. While I'm fixing it I quarantine the test so it doesn't block the pipeline. Finally I monitor it for a few runs. If the test no longer adds value I delete it instead of keeping it.
