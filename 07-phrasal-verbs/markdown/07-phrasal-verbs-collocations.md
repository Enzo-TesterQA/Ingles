# Phrasal verbs y collocations de trabajo

Oct 13, 2026 · @Enzo

Los phrasal verbs y las combinaciones fijas de palabras son lo que hace que tu inglés suene natural en vez de traducido. Acá están los que más se usan en equipos de QA y desarrollo.

## Cómo funcionan

Un phrasal verb es un verbo + una partícula (up, out, down, back, on, off...) que juntos tienen un significado propio: *set up* no es "poner arriba", es "configurar".

| Tipo | Regla | Ejemplo |
| --- | --- | --- |
| Separable | El objeto puede ir en el medio o al final. Si el objeto es un pronombre (it, them), va **siempre en el medio**. | I set up the pipeline. / I set the pipeline up. / I set **it** up. (nunca "I set up it") |
| No separable | El objeto va siempre después de la partícula. | I ran into a problem. / I ran into **it**. |
| Sin objeto | No llevan objeto. | The build broke down. / The service went down. |

**Conjugación:** se conjuga solo el verbo, la partícula no cambia: *set up, set up, set up* / *ran into* / *has figured out* / *is rolling back*.

| --- | --- | --- |

| narrow down | acotar | I narrowed down the problem to one specific browser. |
| roll back | revertir un deploy | We rolled back the release after the error spike. |
| roll out | lanzar de forma gradual | We're rolling out the feature to 10% of users. |
| break down | dividir en partes / dejar de funcionar | Let's break down this story into smaller tasks. / The runner broke down. |
| go down | caerse (un servicio) | The staging server went down during the demo. |
| come up | surgir | A critical bug came up the day before the release. |
| pick up | tomar una tarea | I'll pick up the ticket for the login tests. |
| clean up | limpiar | Each test cleans up its own data. |
| look into | investigar | I'll look into the failing tests after lunch. |
| check out | revisar / bajar una rama | Check out this branch and run the tests locally. |

## Collocations: qué verbo va con cada sustantivo

En español decimos "hacer" para casi todo. En inglés cada sustantivo tiene su verbo.

| Verbo | Va con | Ejemplo |
| --- | --- | --- |
| run | tests, a suite, a pipeline, a query, a script | I ran the regression suite last night. |
| write | tests, test cases, a bug report, code, documentation | I wrote a detailed bug report. |
| file / log / raise / open | a bug, a ticket, an issue | I filed a bug in Jira. / I raised the issue with the PM. |
| fix | a bug, an issue, a test | The dev fixed the bug in an hour. |
| make | a decision, a mistake, a change, progress, a suggestion | We made the decision to delay the release. |
| do | a review, research, testing, a demo, your job | I did a code review of the test PR. |
| take | time, a look, notes, ownership, a break | Can you take a look at this failure? |
| give | feedback, a presentation, an estimate, a demo | I gave a demo of the new framework. |
| meet | a deadline, requirements, expectations | We met the deadline. |
| miss | a deadline, a bug, a meeting | We missed a bug in the payment flow. |
| reach | a goal, an agreement, a conclusion | We reached an agreement on the scope. |
| set | a goal, a deadline, priorities, expectations | I set clear expectations with the team. |
| gain | experience, knowledge, visibility | I gained a lot of experience with APIs. |
| catch | a bug, an error, an exception | The tests caught the bug before production. |
| ship / release | a feature, a version, a fix | We shipped the feature on Friday. |
| increase / improve | coverage, quality, performance | I increased coverage to 80%. |
| reduce / cut | time, costs, flakiness | We cut the pipeline time in half. |
| attend / join | a meeting, a call | I joined the call five minutes late. |
| ask | a question | Can I ask a question about the requirements? |
| pay | attention | Pay attention to the error messages. |

**Error típico:** "make a test", "make a question", "do a mistake", "realize a test". Lo correcto: **run / write a test**, **ask a question**, **make a mistake**, **carry out a test**.

## Expresiones idiomáticas de trabajo

| Expresión | Significado | Ejemplo |
| --- | --- | --- |
| on track | en camino, según lo planeado | The release is on track for Friday. |
| behind schedule | atrasado | We're a bit behind schedule because of the blocker. |
| a quick win | una mejora rápida y fácil | Adding retries to the API client was a quick win. |
| low-hanging fruit | lo más fácil de resolver primero | Let's start with the low-hanging fruit. |
| the bottleneck | el cuello de botella | Manual regression was the bottleneck. |
| a moving target | algo que cambia todo el tiempo | The requirements were a moving target. |
| in the loop | informado | Keep me in the loop on the fix. |
| up to speed | al día | It took me a week to get up to speed with the codebase. |
| on the same page | alineados | Let's make sure we're on the same page. |
| hands-on experience | experiencia práctica | I have hands-on experience with Appium. |
| from scratch | desde cero | I built the framework from scratch. |
| out of the box | listo para usar | Playwright supports parallel execution out of the box. |
| a learning curve | lo que cuesta aprender algo | Cypress has a small learning curve. |
| to cut corners | hacer las cosas a medias | We can't cut corners on payment testing. |
| a red flag | señal de alarma | A test that never fails is a red flag. |
| to ring a bell | sonar conocido | That error message rings a bell. |
| to touch base | contactarse brevemente | Let's touch base on Monday. |
| ballpark figure | número aproximado | Can you give me a ballpark figure for the testing effort? |
| it's not rocket science | no es tan difícil | Writing a good bug report isn't rocket science. |
| to go the extra mile | hacer más de lo esperado | She always goes the extra mile with test documentation. |
