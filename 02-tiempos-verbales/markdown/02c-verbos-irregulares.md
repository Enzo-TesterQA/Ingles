# Verbos irregulares para QA

Oct 15, 2026 · @Enzo

## Las tres formas verbales

Todo verbo en inglés tiene tres formas. Para los irregulares, ninguna sigue la regla del **-ed**.

| Forma | Nombre técnico | Cuándo se usa | Ejemplo |
| --- | --- | --- | --- |
| **Base** | infinitivo sin "to" | Simple present, imperativo, después de modales (can, must, will) | *I write tests every day.* |
| **Past simple** | pasado simple | Acción completada en el pasado (momento específico) | *I wrote 20 tests yesterday.* |
| **Past participle** | participio pasado | Perfect tenses (have/has/had + PP) y voz pasiva | *I've written 200 tests this year.* |

**Regla de oro:** después de have / has / had, siempre va el participio, no el pasado simple.

> ❌ I have wrote → ✅ I have **written** ❌ I have went → ✅ I have **gone**

## Patrones de irregularidad

Hay cuatro patrones. Aprendé el grupo, no cada verbo por separado.

### AAA — las tres formas son iguales

| Base | Past simple | Past participle | Significado |
| --- | --- | --- | --- |
| cut | cut | cut | cortar, eliminar |
| let | let | let | dejar, permitir |
| set | set | set | configurar |

| put | put | put | poner, colocar |
| cost | cost | cost | costar |
| read\* | read | read | leer |

\*read: se escribe igual pero se pronuncia /rɛd/ en pasado y participio.

### ABA — participio = base (≠ pasado)

¡Cuidado! El participio vuelve a la forma base.

| Base | Past simple | Past participle | Significado |
| --- | --- | --- | --- |
| run | ran | run | ejecutar, correr |
| come | came | come | venir |
| become | became | become | volverse, convertirse |

## Errores típicos

Los errores más comunes de hispanohablantes con verbos irregulares.

### Error 1: usar pasado simple después de have

En español *hable* y *hablado* suenan muy distintos, pero en inglés algunos pares son similares y se confunden.

| ❌ Incorrecto | ✅ Correcto | Regla |
| --- | --- | --- |
| I have **wrote** the test | I have **written** the test | ABB → ABC: pasado ≠ participio |
| I have **went** to the meeting | I have **gone** to the meeting | went es solo pasado simple |
| I have **ran** 500 tests | I have **run** 500 tests | Grupo ABA: participio = base |
| I have **came** from a QA background | I have **come** from a QA background | Grupo ABA: participio = base |
| I have **saw** this error before | I have **seen** this error before | saw es solo pasado simple |
| I have **broke** the build | I have **broken** the build | broke es solo pasado simple |
| I have **took** ownership | I have **taken** ownership | took es solo pasado simple |

### Error 2: aplicar -ed a verbos irregulares

| ❌ Incorrecto | ✅ Correcto |
| --- | --- |
| I **writed** the documentation | I **wrote** the documentation |
| I **finded** the bug | I **found** the bug |
| I **leaded** the team | I **led** the team |
| I **builded** the pipeline | I **built** the pipeline |
| I **thinked** it was a network issue | I **thought** it was a network issue |

### Error 3: confundir run (grupo ABA)

Como *run* en simple past es *ran*, muchos dicen *have ran*. No: participio de run es run.

> ❌ I have **ran** the tests three times. → ✅ I have **run** the tests three times.

Lo mismo con *come* → came → come y *become* → became → become.
