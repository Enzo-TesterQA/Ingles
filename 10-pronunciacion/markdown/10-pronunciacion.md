# Pronunciación para entrevistas técnicas

Oct 13, 2026 · @Enzo

No hace falta sonar nativo: hace falta que te entiendan a la primera. Esta guía se enfoca en las palabras y sonidos que más confusión generan cuando un hispanohablante habla de testing y software. La pronunciación aparece en mayúsculas aproximadas (la sílaba en mayúscula es la acentuada).

## 2. Terminación -ed: las tres pronunciaciones

Es clave porque el pasado de casi todos los verbos de tus logros termina en -ed. La -ed casi nunca suena como una sílaba "ed" extra.

| Sonido | Cuándo | Ejemplos de trabajo |
| --- | --- | --- |
| /t/ | El verbo termina en sonido sordo: p, k, s, sh, ch, f, x | fixed (FIKST), reduced (ri-DUUST), worked (WORKT), pushed (PUSHT), checked (CHEKT), released (ri-LIIST), increased (in-KRIIST) |
| /d/ | El verbo termina en sonido sonoro: vocal, b, g, l, m, n, r, v, z | logged (LOGD), improved (im-PRUUVD), designed (di-ZAIND), solved (SOLVD), deployed (di-PLOID), configured (con-FI-gyurd) |
| /ɪd/ (sílaba extra "id") | Solo si el verbo termina en t o d | tested (TES-tid), automated (O-to-mei-tid), integrated (IN-te-grei-tid), migrated (MAI-grei-tid), added (A-did), needed (NII-did) |

**Error típico:** decir "fik-SED", "wor-KED", "re-du-CED". Si agregás una sílaba de más, el oyente puede no entender que estás hablando en pasado.

**Práctica:** leé en voz alta: *I worked on the API, fixed two bugs, tested the new flow, automated the checkout and deployed it to staging.*

## 3. Acento de palabra (word stress)

En inglés, poner el acento en la sílaba equivocada puede hacer que una palabra conocida suene irreconocible. Muchas palabras técnicas son parecidas al español pero con el acento en otro lugar.

| Palabra | Acento | Español (para comparar) |
| --- | --- | --- |
| development | de-VE-lop-ment | desarrollo |
| environment | en-VI-ron-ment | entorno |
| technology | tek-NO-lo-yi | tecnología |
| analysis | a-NA-li-sis | análisis |
| analyze | A-na-laiz | analizar |
| category | KA-te-go-ri | categoría |
| component | com-PO-nent | componente |
| infrastructure | IN-fra-struc-cher | infraestructura |
| performance | per-FOR-mans | rendimiento |
| priority | prai-O-ri-ti | prioridad |
| reliability | ri-lai-a-BI-li-ti | confiabilidad |
| scalability | skei-la-BI-li-ti | escalabilidad |
| maintenance | MEIN-te-nans | mantenimiento |
| validate | VA-li-deit | validar |
| integrate | IN-te-greit | integrar |
| implement | IM-ple-ment | implementar |
| interesting | IN-tres-ting | interesante |
| comfortable | KAMF-ter-bel | cómodo |
| determine | de-TER-min | determinar |
| specific | spe-SI-fik | específico |

**Regla útil:** en las palabras terminadas en **-tion, -sion, -ic, -ity**, el acento cae justo antes de esa terminación: automa-TION se dice o-to-MEI-shon, spe-CI-fic, relia-BI-lity.

**Sustantivo vs verbo:** algunas palabras cambian el acento. *a RE-cord* (un registro) / *to re-CORD* (grabar); *an IN-crease* / *to in-CREASE*; *a PRO-ject* / *to pro-JECT*.

## 4. Sonidos difíciles para hispanohablantes

| Sonido | El problema | Pares para practicar | Truco |
| --- | --- | --- | --- |
| S inicial + consonante | Agregamos una "e": "estart", "eskill" | start, stack, script, staging, skill, sprint, schema | Arrancá con un "sss" largo antes de la consonante. |
| Vocal corta /ɪ/ vs larga /iː/ | Las decimos igual | ship / sheep, fit / feet, bit / beat, live / leave, fill / feel | La corta es más relajada, casi una "e". |
| /æ/ (la a de cat) | Sale como a española | bug / bag, cap / cup, track, stack, app, cache | Abrí la boca como para decir "a" pero con la lengua en posición de "e". |
| Schwa /ə/ | Pronunciamos todas las vocales claras | about, problem, component, develop | Las sílabas sin acento se relajan en un sonido neutro, casi "e". |
| TH sorda /θ/ y sonora /ð/ | Sale como t, d o s | think, method, both, auth / the, this, that, other | Lengua entre los dientes. |
| V vs B | Las decimos igual | very, value, version, video, verify / build, bug, branch | V: dientes de arriba sobre el labio de abajo. |
| H | Sale como j fuerte | hotfix, help, how, hash, header | Es solo aire, suave, como empañar un vidrio. |
| Y / J | Sale como "sh" o "ch" | yes / jest, year / Jenkins, YAML / JSON, Java, JavaScript | J es como "ch" sonora; Y es como la "i" de "hielo". |
| Consonantes finales | Las comemos | test, build, script, sprint, merged, fixed | Terminá cada palabra marcando la última consonante. |
| W | Sale como "gu" | work, write, window, workflow, webhook | Labios redondos, como para decir "u", sin g. |

**Trabalenguas técnicos (leé 3 veces cada uno, cada vez más rápido):**

1. *The test suite's staging script started with six skipped specs.*
2. *I think the third method throws an authentication error.*
3. *We verified the new version of the video viewer via the web view.*
4. *Jenkins and Jest run the JavaScript jobs, YAML configures the rest.*
5. *The fixed, tested and deployed build passed all checks.*

## 5. Cómo leer símbolos, números y código en voz alta

En una entrevista técnica o en pair programming vas a tener que dictar código, URLs y versiones.

| Símbolo | Se dice | Símbolo | Se dice |
| --- | --- | --- | --- |
| . | dot | / | slash (forward slash) |
| \\ | backslash | \_ | underscore |
| - | dash / hyphen / minus | @ | at |
| # | hash / pound | \~ | tilde |
| \| | pipe | & | ampersand / and |
| \* | asterisk / star | = | equals |
| == | double equals | ! | exclamation mark / bang |
| ( ) | parentheses (open / close paren) | \[ \] | square brackets |
| { } | curly braces | < > | angle brackets / less than, greater than |
| : | colon | ; | semicolon |
| " | double quote | ' | single quote |
| $ | dollar sign | % | percent |

| Escrito | Se dice |
| --- | --- |
| v2.3.1 | version two point three point one |
| 404 / 500 | four oh four / five hundred |
| 99.9% | ninety-nine point nine percent |
| 0.5 | zero point five / point five |
| 1,500 | one thousand five hundred / fifteen hundred |
| 2025 | twenty twenty-five |
| 3 ms / 2 s | three milliseconds / two seconds |
| 10x faster | ten times faster |
| api.example.com/v1/users | API dot example dot com slash v one slash users |
| getUserById() | get user by ID, open and close parentheses |
| user\_id | user underscore ID |
| QA-231 | Q A two three one |

**Fechas y horas:** *October 13th* (October thirteenth), *at 3 pm* (three p m), *GMT-3* (G M T minus three).

**Truco:** cuando dictes algo largo, agrupá y confirmá: "It's api dot example dot com... slash v one... slash users. Did you get that?"

## 6. Cómo practicar

**Shadowing (10 minutos por día):**

1. Elegí un video corto de un ingeniero hablando de testing o IA (una charla de conferencia, un tutorial de Playwright, un podcast técnico).
2. Escuchá una frase, pausá y repetila imitando el ritmo, la entonación y las pausas, no solo las palabras.
3. Repetí el mismo fragmento de 1 minuto durante varios días hasta que te salga fluido.

**Grabarte (una vez por semana):**

1. Grabá tu respuesta a "Tell me about yourself" con el celular.
2. Escuchala y marcá: palabras con -ed mal pronunciadas, sílabas acentuadas mal, muletillas ("eh", "este", "o sea").
3. Compará con la grabación de la semana anterior.

**Dictado por voz:** dictale al celular en inglés tus respuestas de entrevista. Si el dictado escribe otra palabra, es probable que un entrevistador también la entienda mal. Después mandame el texto y lo corregimos.

**Muletillas en inglés (mejor que "eh" o "este"):** *well...*, *so...*, *let me think...*, *basically...* (sin abusar), *I mean...*
